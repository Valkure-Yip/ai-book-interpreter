# 英文源语注记 / English Source Notes (en -> zh-Hans)

## 英文章节标题 / English chapter titles

- 旧英文纸书目录常用 `--` 链接多个主题成一个长标题；按 `chapter_title_policy.md` 拆为
  短目录题名 + 页面主标题 + 可选副标题。
- 章节编号 `Chapter I / II`、`Book One` 等转为自然中文（“第一章”“卷一”）。

## 英译中常见干扰 / Common English->Chinese interference

- 英语长句 → 中文应切分为自然短句群，但不得切成动作清单。
- 被动语态 → 优先转主动。
- 英语抽象名词堆叠 → 还原为动词/具体表达。
- 代词 it/they/this 指代 → 中文需补出明确主语，避免指代不清。
- 古英语/盎格鲁-撒克逊术语（如 thegn、witenagemot）→ 正文用可读译名，原词进译注/术语表。

## 人名地名 / Names

- 音译人名在正文首次自然出现处可保留一次英文原名；其后只用中文译名。
- 标题、副标题、导航标签只用中文译名。
